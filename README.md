# SurvDroid releases

Built artifacts only. The source lives in a private repository.

`latest.json` is the feed the app checks on launch. It is public so the app can
read it without shipping a credential inside the APK.

| File | Device |
| --- | --- |
| `SurvDroid-<version>-phone.apk` | Android phone or tablet |
| `SurvDroid-<version>-windows.zip` | Carlson RT4 and other Windows tablets (not published yet) |
